# Fusion_Tutorial_2023_Belief_Function_Basics
Functional code to demo alongside the tutorial.

in ./tests/Fusion_tutorial_2023.mlx you'll find a MATALB live scrip used in the tutorial

Run instructions:
1. Open MATLAB GUI
2. In MATLAB navigate workspace to top directory ("./") where repo was cloned
3. Open ./tests/Fusion_tutorial_2023.mlx in MATLAB
4. Run Fusion_tutorial_2023.mlx in MATLAB

Note: Ran in MATLAB 2021a and later.  Also, created in house bi2de and de2bi functions to remove toolbox dependencies.
